# Personal Data Website

This project is a personal data storage website designed to hold information such as university, home, and office details. The website features a beautiful user interface built using HTML, CSS, JavaScript, Bootstrap, and Tailwind CSS.

## Project Structure

The project is organized as follows:

```
personal-data-website
├── public
│   ├── index.html         # Main HTML document for the website
│   ├── favicon.ico        # Favicon for the website
│   └── assets             # Folder for storing images
├── src
│   ├── css
│   │   ├── bootstrap.css   # Bootstrap CSS framework
│   │   ├── tailwind.css    # Tailwind CSS framework
│   │   └── styles.css      # Custom CSS styles
│   └── js
│       └── main.js         # JavaScript for interactivity
├── package.json            # npm configuration file
├── tailwind.config.js      # Tailwind CSS configuration
├── postcss.config.js       # PostCSS configuration
└── README.md               # Project documentation
```

## Setup Instructions

1. **Clone the repository**:
   ```
   git clone <repository-url>
   cd personal-data-website
   ```

2. **Install dependencies**:
   ```
   npm install
   ```

3. **Build the project**:
   ```
   npm run build
   ```

4. **Run the project**:
   ```
   npm start
   ```

## Features

- Responsive design using Bootstrap and Tailwind CSS.
- Custom styles for a unique look and feel.
- JavaScript functionality for dynamic content and interactivity.

## Usage

You can store and manage your personal data, including university, home, and office information, through the user-friendly interface provided by this website. Images can be added to the `public/assets` folder for use throughout the site.
